OpenCode Assistant

Um widget de chat com IA para KDE Plasma 6, usando o opencode CLI, com pet animado do Tux.

KDE Plasma 6 QtWebEngine opencode CLI Licença MIT
$ curl -fsSL https://raw.githubusercontent.com/zonaro/opencode-assistant-kde/main/scripts/install.sh | bash

Este comando instala o opencode CLI (se não existir), o widget e seu backend, e reinicia o plasmashell.

Recursos

🐧

Pet Tux

Companheiro animado que reage ao status do chat, anda até onde você clicar, pula ao passar o mouse, muda de tamanho com o scroll e mostra animação de erro quando offline.

💬

Chat com streaming

Respostas em tempo real com seletor de modelo e anexos de arquivos.

🗂

Múltiplas conversas

Crie, alterne e exclua conversas.

⚙️

Configuração completa

Personalidade, contexto do usuário, permissões por pasta, memórias e opções do pet.

Requisitos

  • KDE Plasma 6 (Qt 6) com QtWebEngine
  • Node.js ≥ 20
  • curl
  • kpackagetool6 (do pacote kpackage, incluído no Plasma 6)

Como usar

1. Instalar

curl -fsSL https://raw.githubusercontent.com/zonaro/opencode-assistant-kde/main/scripts/install.sh | bash

O instalador baixa os arquivos deste repositório para ~/.local/share/opencode-assistant-kde/, instala o plasmoid e baixa o pet padrão Tux sob demanda.

2. Adicionar o widget

Clique com o botão direito na área de trabalho → Adicionar Widgets… → procure por OpenCode Assistant.

3. Fazer login no opencode

Em um terminal:

opencode auth login

Depois é só escolher o provedor e o modelo dentro do widget.

Instalação manual

A partir de um checkout deste repositório:

./scripts/install.sh

Ou instale apenas o pacote do plasmoid:

kpackagetool6 --type Plasma/Applet --install package

Desenvolvimento

Execute o backend localmente (serve a UI em http://127.0.0.1:3171/):

node backend/index.js

Execute todos os testes:

./scripts/test.sh

Pré-visualize o widget sem instalar:

plasmoidviewer -a package -l floating -f planar
