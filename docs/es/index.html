OpenCode Assistant

Un widget de chat con IA para KDE Plasma 6, impulsado por el CLI de opencode, con la mascota animada de Tux.

KDE Plasma 6 QtWebEngine opencode CLI Licencia MIT
$ curl -fsSL https://raw.githubusercontent.com/zonaro/opencode-assistant-kde/main/scripts/install.sh | bash

Este comando instala el CLI de opencode (si falta), el widget y su backend, y reinicia plasmashell.

Características

🐧

Mascota Tux

Compañero animado en el escritorio que reacciona al estado del chat.

💬

Chat en streaming

Respuestas en tiempo real con selector de modelo y archivos adjuntos.

🗂

Múltiples sesiones

Crea, cambia y elimina conversaciones.

⚙️

Configuración completa

Personalidad, contexto del usuario, permisos por carpeta, recuerdos y opciones de la mascota.

Requisitos

  • KDE Plasma 6 (Qt 6) con QtWebEngine
  • Node.js ≥ 20
  • curl
  • kpackagetool6 (del paquete kpackage, incluido en Plasma 6)

Primeros pasos

1. Instalar

curl -fsSL https://raw.githubusercontent.com/zonaro/opencode-assistant-kde/main/scripts/install.sh | bash

El instalador descarga las fuentes de este repositorio a ~/.local/share/opencode-assistant-kde/, instala el plasmoid y descarga la mascota por defecto Tux bajo demanda.

2. Añadir el widget

Click derecho en el escritorio → Añadir widgets… → busca OpenCode Assistant.

3. Iniciar sesión en opencode

En una terminal:

opencode auth login

Luego elige tu proveedor y modelo dentro del widget.

Instalación manual

Desde un checkout de este repositorio:

./scripts/install.sh

O instala solo el paquete del plasmoid:

kpackagetool6 --type Plasma/Applet --install package

Desarrollo

Ejecuta el backend localmente (sirve la UI en http://127.0.0.1:3171/):

node backend/index.js

Ejecuta todas las comprobaciones:

./scripts/test.sh

Vista previa del widget sin instalarlo:

plasmoidviewer -a package -l floating -f planar
