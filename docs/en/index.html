OpenCode Assistant

An AI chat widget for KDE Plasma 6, powered by the opencode CLI, with an animated Tux pet.

KDE Plasma 6 QtWebEngine opencode CLI MIT License
$ curl -fsSL https://raw.githubusercontent.com/zonaro/opencode-assistant-kde/main/scripts/install.sh | bash

This command installs opencode CLI (if missing), the widget, and its backend, then restarts plasmashell.

Features

🐧

Tux pet

Animated desktop companion that reacts to chat status, can be dragged around the widget, and shows a red dot when offline.

💬

Streaming chat

Real-time responses with a model picker and file attachments.

🗂

Multiple sessions

Create, switch and delete conversations.

⚙️

Full settings

Personality, user context, per-folder permissions, memories, pet options.

Requirements

  • KDE Plasma 6 (Qt 6) with QtWebEngine
  • Node.js ≥ 20
  • curl
  • kpackagetool6 (from the kpackage package, shipped with Plasma 6)

Getting started

1. Install

curl -fsSL https://raw.githubusercontent.com/zonaro/opencode-assistant-kde/main/scripts/install.sh | bash

The installer downloads the sources from this repository into ~/.local/share/opencode-assistant-kde/, installs the plasmoid bundle, and fetches the default Tux pet on demand.

2. Add the widget

Right-click the desktop → Add Widgets… → search for OpenCode Assistant.

3. Log in to opencode

In a terminal:

opencode auth login

You will be able to pick your provider and model inside the widget.

Manual install

From a checkout of this repository:

./scripts/install.sh

Or install just the plasmoid bundle:

kpackagetool6 --type Plasma/Applet --install package

Development

Run the backend locally (serves the UI at http://127.0.0.1:3171/):

node backend/index.js

Run all checks:

./scripts/test.sh

Preview the widget without installing it:

plasmoidviewer -a package -l floating -f planar
